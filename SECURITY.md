# Política de Seguridad

## Versiones compatibles

Actualmente, la rama principal (`main`) es la versión de desarrollo activa de KimiXP.

Las versiones publicadas pueden recibir correcciones de seguridad según su estado de mantenimiento.

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad en KimiXP, **no la publiques en una Issue pública**.

En su lugar, contacta de forma privada con los mantenedores del proyecto y proporciona:

- Una descripción de la vulnerabilidad.
- Los pasos necesarios para reproducirla.
- El impacto potencial.
- Cualquier información adicional que pueda ayudar a investigar el problema.

## Información sensible

Nunca publiques:

- Tokens de Discord.
- Contraseñas.
- Claves API.
- Credenciales.
- Archivos `.env`.
- Información privada.

Si un token o credencial se expone accidentalmente, debe revocarse inmediatamente y reemplazarse por uno nuevo.

## Proceso de respuesta

Los mantenedores revisarán los reportes de seguridad y determinarán las medidas necesarias para solucionar el problema.

Cuando sea apropiado, se publicará una corrección en una nueva versión de KimiXP.

## Alcance

Esta política se aplica al código y los componentes oficiales de KimiXP mantenidos dentro de este repositorio.
